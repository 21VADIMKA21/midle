# OBS: отдельный музыкальный канал

> Статус: инструкция подготовлена, но ещё не проверена на компьютере стримера. Перед полноценным эфиром обязательна короткая запись и тестовый VOD.

## Цель

- музыка слышна зрителям в прямом эфире;
- музыка не попадает в Twitch VOD;
- музыка не попадает в локальную запись OBS;
- микрофон, игра и нужные оповещения остаются во всех трёх вариантах.

## 1. Отдельный аудиовыход для Fusion Player

Рекомендуемый вариант для Windows — VB-Audio VB-CABLE.

1. Скачать VB-CABLE только с официального сайта: https://vb-audio.com/Cable/VirtualCables.htm
2. Распаковать архив.
3. Запустить установщик x64 от имени администратора.
4. Перезагрузить Windows, если установщик этого потребует.
5. В Fusion Player выбрать устройство вывода **CABLE Input (VB-Audio Virtual Cable)**.
6. В OBS добавить источник **Audio Input Capture** и выбрать **CABLE Output (VB-Audio Virtual Cable)**.

Направление кабеля важно: приложение воспроизводит звук в CABLE Input, а OBS захватывает его из CABLE Output.

Не добавлять Fusion Player одновременно как отдельный источник и в общий Desktop Audio: это может дать двойной звук.

### Чтобы стример тоже слышал музыку

- В OBS открыть **Settings → Audio → Advanced** и выбрать свои наушники как **Monitoring Device**.
- В **Advanced Audio Properties** для источника CABLE Output установить **Audio Monitoring → Monitor and Output**.
- Убедиться, что мониторинг OBS не возвращается обратно в захватываемый Desktop Audio, иначе появится эхо или двойной сигнал.

## 2. Дорожки OBS

В **Settings → Stream** выбрать Twitch и подключить аккаунт. Затем переключить **Settings → Output → Output Mode → Advanced**.

### Streaming

- Основная аудиодорожка эфира: **Track 1**.
- Включить **Twitch VOD Track** и назначить **Track 2** для VOD.

### Recording

- Включить локальную запись на **Track 3**.
- В настройках записи выбрать только Track 3, если в локальном файле музыка должна отсутствовать.

### Advanced Audio Properties

Открыть микшер OBS → шестерёнка → **Advanced Audio Properties**.

| Источник | Track 1 — эфир | Track 2 — Twitch VOD | Track 3 — локальная запись |
|---|---:|---:|---:|
| Микрофон | Да | Да | Да |
| Игра / системный звук | Да | Да | Да |
| Оповещения, которые должны сохраниться | Да | Да | Да |
| Fusion Player / CABLE Output | Да | Нет | Нет |

Если какой-либо источник уже содержит музыку внутри общего системного звука, одной этой схемы недостаточно: сначала нужно отделить его аудио.

## 3. Проверка перед эфиром

1. Запустить Fusion Player и проверить, что уровень CABLE Output двигается в микшере OBS.
2. Включить тестовый трек, микрофон и игру.
3. Сделать локальную запись на 30–60 секунд.
4. Проверить, что в локальной записи слышны микрофон и игра, но нет музыки.
5. Провести короткий тестовый эфир и дождаться обработки VOD.
6. Проверить VOD: микрофон и игра должны быть слышны, музыка — отсутствовать.
7. Если хотя бы одна проверка не прошла, не считать разделение настроенным.

Twitch VOD Track отделяет аудио VOD от прямого эфира, но сам по себе не исключает музыку из локальной записи. Для этого нужна отдельная дорожка записи, как описано выше.
