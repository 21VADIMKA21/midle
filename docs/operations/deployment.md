# Production deployment

Fusion Music is prepared for a Render Blueprint deployment through the repository's `render.yaml`.

## Resources

The Blueprint defines:
- one Node.js web service, which runs Next.js and the Twitch chat worker under one supervisor;
- one managed PostgreSQL database;
- automatic SQL migrations before deployment;
- an HTTP health check at `/api/health`;
- automatic deployment only after GitHub checks pass.

The selected instance sizes are intentionally small for a single Twitch channel. Render resources are paid; review the current Render pricing and the monthly estimate in the Render dashboard before creating them. Do not approve charges until the owner has reviewed them.

## Required Twitch configuration

After Render assigns the public service URL:

1. Create a Twitch application in https://dev.twitch.tv/console/apps.
2. Set the OAuth Redirect URL to the exact value:
   `https://<render-service-host>/api/auth/callback`
3. Copy the Twitch Client ID and Client Secret into the Render environment variables `TWITCH_CLIENT_ID` and `TWITCH_CLIENT_SECRET`.
4. Set `TWITCH_REDIRECT_URI` to the same exact callback URL.
5. Keep `TOKEN_ENCRYPTION_KEY` generated by Render. Never rotate it after tokens have been stored unless all stored Twitch tokens are re-authorized.

The database URL is wired from the managed Render PostgreSQL resource. Do not copy database credentials into source files or commit a production `.env`.

## Deployment verification

After the Blueprint deploys:

1. Open `https://<render-service-host>/api/health`. It must return HTTP 200 and report a connected database.
2. Open `/dashboard` and connect the broadcaster's Twitch account.
3. Confirm the chat worker status becomes connected.
4. Pair the local Fusion Player and sync the authorized music folder.
5. Re-confirm music rights before enabling requests.
6. Test `!трек`, `!скип`, queue updates, and player recovery.
7. Complete the OBS audio isolation checklist in [obs-audio.md](obs-audio.md).

A green health check only proves that the web service and database are reachable. It does not replace the live Twitch, local player, or OBS end-to-end test.
