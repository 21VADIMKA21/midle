# Fusion OBS Overlay

Публичная браузерная сцена для OBS: `/overlay`.

## Подключение

1. Добавь в OBS источник **Browser**.
2. Укажи URL: `https://midle-production-2556.up.railway.app/overlay`.
3. Размер: 720 × 520.
4. Включи обновление страницы при активации источника, если используешь скрытие источника между сценами.

Overlay запрашивает `GET /api/queue` каждые 3 секунды. Он показывает только серверные метаданные очереди: текущий трек, автора заявки, обложку и следующие позиции. Аудио он не воспроизводит и не захватывает.

## Важно

Это визуальный источник OBS, а не музыкальный аудиоплеер. Для облачного аудио нужен отдельный источник, который письменно разрешает внешний request playback и трансляцию на Twitch. Spotify/YouTube ссылки или подписки сами по себе такого разрешения не дают.
