# Fusion Music

Веб-сервис музыкальных заявок для Twitch-канала Fusion.

## Статус

Начальный каркас проекта. Это пока интерфейс-прототип: он не подключён к Twitch, YouTube, Spotify, базе данных или OBS и не воспроизводит музыку. Интеграции будут добавляться отдельными этапами.

## План разработки

1. Публичная страница: текущий трек, очередь, обложки, автор заявки.
2. Приём ссылок и проверка поддерживаемых источников.
3. Сервер и постоянное хранение очереди.
4. Вход владельца через Twitch OAuth и панель управления.
5. Локальный плеер для Windows и OBS Browser Source.
6. Twitch-бот: `!трек`, голосование `скип/skip`, принудительный пропуск.
7. Разделение аудиодорожек для трансляции, VOD и локальной записи.

## Локальный запуск

Требуется Node.js 20.9+.

```bash
npm install
npm run dev
```

Откройте http://localhost:3000.

## Важные ограничения

- Очередь должна храниться на сервере, чтобы сайт не зависел от Twitch-чата или OBS.
- Воспроизведение в эфире требует работающего локального плеера на ПК стримера.
- Поддержка конкретных ссылок зависит от правил и технических ограничений YouTube, YouTube Music и Spotify. Нельзя считать, что любая ссылка будет воспроизводиться или что её можно ретранслировать.
- Секреты OAuth/API хранятся только в переменных окружения на сервере; их нельзя добавлять в Git.
